# Configs

- `bot.yaml` — keybinds, hotkeys, skill timing, watchdog thresholds (created in phase 0/2)
- `maps/<map>.yaml` — minimap box, platforms, ropes, patrol zone (owned by `map-modeler`)
- `local*.yaml` — your personal overrides; git-ignored

Thresholds, keybinds and timings belong here, never hard-coded in `src/`.
